# Web Application - Bootstrapping Database and RESTful API

## Project Overview

This project is a web application that bootstraps a MySQL database and provides a set of RESTful APIs to manage user accounts. The application uses Python with Flask as the web framework and SQLAlchemy as the ORM.

### Key Features:
- **Database Bootstrapping**: The application automatically creates and updates the database schema.
- **RESTful APIs**: Users can create, update, and retrieve account information.
- **Basic Authentication**: API endpoints are secured with basic authentication using bcrypt for password hashing.
- **Database**: The application supports MySQL or PostgreSQL databases.

## Prerequisites

Make sure the following software is installed on your machine or cloud environment (e.g., DigitalOcean VM):

- Python 3.9+
- MySQL or PostgreSQL
- Node.js and npm (if required for your application)
- Java (if required for your application)
- Flask
- SQLAlchemy
- Flask-Bcrypt
- Flask-HTTPAuth
- curl/Postman (for testing APIs)
